# chicken-amr-wetmarket-metagenomics
Antimicrobial resistance (AMR) and mobile genetic element (MGE) analysis pipeline for long-read metagenomic sequencing of samples collected from industrial broiler farms and wet-markets. Covers QC, host depletion, taxonomic classification, assembly, MAG binning/annotation, AMR/MGE detection, and AMR–MGE co-localisation analysis.
